# Bank Customer Churn Analysis

## Project Overview
This project analyzes bank customer data to understand customer churn patterns and identify factors that influence customers to leave the bank.

## Dataset
- Total Records: 10,000
- Total Columns: 14
- Churned Customers: 2,037
- Churn Rate: 20.37%

## Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Work
1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Customer Churn Analysis
5. Age Group Analysis
6. Gender Analysis
7. Geography Analysis
8. Data Visualization

## Key Findings
- Analyzed customer churn distribution.
- Studied churn patterns across age groups.
- Compared churn rates by gender and geography.
- Identified customer segments with higher churn.

## Conclusion
This project helped understand customer churn patterns using Python and data visualization techniques.
